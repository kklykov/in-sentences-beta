# En frases · beta

Landing page and Android test builds of **En frases**, a trainer for Spanish verb forms in context.
The source code lives in a private repository; this repository only publishes the test APKs.

**Page:** https://kklykov.github.io/in-sentences-beta/

| File | For |
|---|---|
| `downloads/en-frases-<version>-arm64.apk` | Most phones (64-bit, Android 8+) |
| `downloads/en-frases-<version>-armv7.apk` | Older 32-bit phones |

All builds are signed with the same key (SHA-256 of the certificate
`7ab5303fceea90aacb1aca95f8e9955fee16f3e949bfa0f852128109c880af15`), so a new version installs over
the previous one.

The Onest font in `fonts/` is under the SIL Open Font License (`fonts/OFL.txt`).
